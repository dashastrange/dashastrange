## What I Do

> **AI systems are the new software — and they fail in entirely new ways.**
> I design orchestration flows for agentic systems and build the validation layers that keep them honest: evals, guardrails, output verification, and behavioral testing.

- **Orchestration** — designing multi-agent workflows with LangGraph: routing, state management, handoffs, human-in-the-loop
- **Validation** — structured output enforcement with Pydantic, eval pipelines, regression testing for prompts and agents
- **LLM Quality** — hallucination detection, output consistency checks, RAG relevance validation
- **QA DNA** — 10 years of test design, edge-case hunting, and "what could possibly go wrong" thinking, now applied to non-deterministic systems

## Why QA → AI Validation Is a Natural Evolution

| Then (Manual QA) | Now (AI Systems) |
|---|---|
| Finding edge cases in UIs | Finding edge cases in agent behaviors |
| Test cases & acceptance criteria | Evals, benchmarks & success metrics |
| Regression testing | Prompt & model regression testing |
| Bug advocacy with devs | Feedback loops for agent improvement |
| "Does it work?" | "Does it work, *and can we trust it?*" |
